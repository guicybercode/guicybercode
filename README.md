# guicybercode

**`indie dev — code / hardware / electronics`**

I like knowing what's actually happening under the abstraction. That's why I write Rust and C for things that talk to metal, and Elixir, Go, and TypeScript for things that talk to people. Most of my bugs get fixed at 2am on a ThinkPad running Gentoo, and I regret nothing.

Things I hold as convictions, not preferences:

- **Open source is a philosophy, not a distribution model.** Software you can't read is software you have to trust blindly.
- **Financial privacy is a human right.** Not a feature, not a nice-to-have.
- **If you don't understand the layer below the one you work on, you're guessing.** Assembly won't hurt you.
- **Plain text outlives everything.** Emacs, org-mode, git. My config files will outlive most startups.

I study languages the way I study systems — to understand from the inside. Portuguese and English fluently; Korean, Icelandic, Italian, Japanese, and Mandarin at the level where I can embarrass myself confidently.

When I'm not compiling, I'm composing. Music and code are the same discipline: structure, tension, resolution.
